# odoo_zhr_ajustes
Adaptaciones al Modulo Empleados de Odoo

- Administra las funciones operativas de cada empleado.
- Incluye el perfil **Asignar funciones a empleados**, basado en el perfil de
  consulta y sin permisos para modificar otros datos de la ficha.
